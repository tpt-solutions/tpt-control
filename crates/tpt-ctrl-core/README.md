# tpt-ctrl-core

Foundation crate: dimensioned state-space models, from-scratch dense linear algebra (LU, Cholesky, QR, real Schur, expm), Lyapunov solvers, exact ZOH/Tustin discretization, RK4. `no_std` + `alloc`.

Part of the [tpt-control](https://github.com/tpt-solutions/tpt-control) workspace. Dual-licensed MIT / Apache-2.0.
