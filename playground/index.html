tpt-control playground

Design an LQR gain in your browser and check it with a certificate. Everything runs locally in WebAssembly.

Press “Design & certify”.

Numbers are separated by spaces, commas or new lines. Values are read as row-major. The certificate checks the relative Riccati residual (≤ 1e-8) and that the closed loop is strictly stable.

Serve this folder over HTTP (for example python -m http.server from the repo root and open /playground/): browsers block WebAssembly modules from file://.
